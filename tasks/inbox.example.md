# Inbox

Add one task per line, then give extra detail on indented lines below it if needed.
Format: `- [ ] [type] (priority) title — details`
Types: `[research]` `[code]` `[brief]` `[docs]`  ·  Priority: `(high)` `(normal)` `(low)`. Leaving it out means normal.
For code tasks, name the repo: a local path or a GitHub `owner/repo`.

Examples (the run skips anything in this comment block):
